# GoLC — Go Line Counter

**GoLC** counts physical lines of source code (LoC) across your repositories on Bitbucket Cloud/DC, GitHub.com/Enterprise, GitLab.com/Self-Managed, and Azure DevOps, using the same language definitions as SonarQube. Full documentation is organized by section below.
