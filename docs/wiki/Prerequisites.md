# Prerequisites

- **Personal access tokens** for Bitbucket Cloud, Bitbucket DC, GitHub, GitLab, and Azure DevOps. The token must have:
  - repo scope
  - Perform pull request actions
  - Push, pull and clone repositories  
  - For GitLab, the permissions needed are: `read_repository`, `read_api`

- [Go language installed](https://go.dev/) — if you want to use the sources.
